# GitLine

GitLine 是一个 Obsidian 桌面端插件，在当前光标所在行的行尾显示该行的 Git 归属信息：提交人、提交时间与提交消息，显示格式可完全自定义。

![preview](image/README/preview.png)

[English](README.md)

## 功能特性

- **行尾归属**：当前光标所在行的 Git 归属信息以内联标注的形式渲染在该行行尾。
- **格式可配置**：可通过 `{date}`、`{time}`、`{author}`、`{message}`、`{hash}` 占位符自由组合显示内容与顺序。
- **灵活的时间**：可选择相对时间（如"3 天前"）或绝对时间，精确到分钟。
- **未提交行**：尚未提交的行会标记为"未提交"。
- **状态栏**：在状态栏显示当前行的提交人（可选）。
- **空白处理**：可开启 `git blame -w`，忽略仅空白的改动。
- **缓存**：LRU 缓存避免重复调用 `git`；文件保存后自动失效。
- **健壮性**：自动检测 git；git 不可用时给出友好提示而非报错。

## 环境要求

- Obsidian **桌面版**（插件使用 Node.js API，仅限桌面端）。
- **Git** 已安装并加入 `PATH`（`git --version` 可执行）。

## 安装

1. 将 `gitline` 插件文件夹复制到 `<你的vault>/.obsidian/plugins/gitline/`。
2. 在 Obsidian 中打开 **设置 → 第三方插件**，启用 **GitLine**。

> 插件正式发布后，也可直接从社区插件列表安装。

## 使用方法

打开位于 Git 仓库中的笔记并移动光标，当前行的 Git 归属信息即显示在该行行尾。

## 设置项

| 设置项       | 说明                                                           | 默认值                        |
| ------------ | -------------------------------------------------------------- | ----------------------------- |
| 启用         | 行尾归属显示总开关。                                           | 开                            |
| 显示格式     | 使用占位符`{date} {time} {author} {message} {hash}` 的模板。 | `{author} {time} {message}` |
| 时间样式     | `相对`（如"3 天前"）或 `绝对`（精确到分钟）。              | 绝对                          |
| 绝对时间格式 | Moment 格式串。                                                | `YYYY-MM-DD HH:mm`          |
| 未提交行     | 在未提交的行上显示标记。                                       | 开                            |
| 忽略空白     | 映射为`git blame -w`。                                       | 关                            |
| 状态栏       | 在状态栏显示当前行的提交人。                                   | 开                            |
| 缓存文件数   | LRU 缓存最多保留的文件个数。                                   | 100                           |
